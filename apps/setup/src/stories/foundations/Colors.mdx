# Colors

SetUp's color tokens, translated from the Paper exploration (`setup-product-flow`) into `src/index.css`. This page renders the live CSS custom properties — if a swatch looks wrong, the token itself is wrong, not this page.

**Approved 2026-08-14.** This is the canonical semantic source of truth for SetUp, defined by the user after a full audit of the current Paper file (6 screens: Home, Workout Overview, three Workout Mode states, Workout Completion). Paper remains the *visual* reference; this list is the *semantic* one. Don't infer, rename, or add color tokens without asking first. Treat this page as fixed unless the user revises it, even if Paper drifts further — unlike the other Foundations pages, this one doesn't get re-audited on a time basis.

Raw palette values. **Not exposed as Tailwind utilities** (`bg-moss` etc. don't exist) — components consume the semantic tokens below, never these directly, unless explicitly approved for a specific case.

**Two screens invert to a dark surface**: Workout Overview and Workout Completion are full-bleed moss with near-white text, instead of the usual light background — `bg-background-inverse text-foreground-inverse`. The "Finish" button is a different thing: it's a single button with its own dark fill (`bg-secondary text-secondary-foreground`) sitting on an otherwise-light Workout Mode screen, not a full-screen inversion — see Button's own docs (Components/Button) for its variant table.

## shadcn compatibility aliases — not canonical

`components/ui/button.tsx` (and any future shadcn-added component) expects `--muted`, `--accent` (plus their `-foreground` pairs), `--card`, `--popover`, `--input`, `--ring`, and `--destructive` to exist, because shadcn's generated code references them. **None of these are part of Color Foundations v1** — they carry no approved product meaning yet. They're kept defined only so existing components don't break, conservatively aliased onto the semantic tokens above. (`--secondary`/`--secondary-foreground` used to be in this bucket too — promoted to canonical 2026-08-14, see the swatch above.)

| shadcn variable | Aliased to |
| --- | --- |
| `--muted` / `--muted-foreground` | `--surface-subtle` / `--foreground-secondary` |
| `--accent` / `--accent-foreground` | `--interactive-subtle` / `--foreground` |
| `--card`, `--popover` (+ foregrounds) | `--background` / `--foreground` (flat surfaces, no distinct card tone) |
| `--input` | `--border` |
| `--ring` | `--foreground` |
| `--destructive` | unchanged shadcn default (no red exists in v1; Paper doesn't style Discard Activity as alarming) |

Don't use these six aliases intentionally in new SetUp components, and don't treat them as approved foundations — they're a compatibility shim, not a design decision. That's also why they're not shown as swatches above.

`--chart-1` through `--chart-5` are likewise unaddressed by v1 (the weekly-graph green that used to live in `--chart-1` no longer exists in Paper — replaced with moss) and are left at shadcn's neutral placeholders.
